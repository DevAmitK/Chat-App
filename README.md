# Chat App  
💬 **A Real-Time Chat Application with Firebase and Modern Features**  

---

## About the App  
The **Chat App** is a user-friendly, real-time messaging application built using Firebase. It provides seamless one-to-one chat functionality with user profile creation, updates, and Google Sign-In for quick and secure access.  

---

## Features  
- **Real-Time Chat**:  
  - Instant one-to-one messaging with real-time updates using **Firebase Firestore**.  

- **User Profiles**:  
  - Create and update user profiles with details like name, profile picture, and bio.  

- **Google Sign-In**:  
  - One-tap Google Sign-In for quick and secure authentication.  

- **Firebase Integration**:  
  - Backend powered by **Firebase Authentication**, **Firestore**, and **Firebase Storage** for data and profile picture handling.  

- **Modern UI**:  
  - Clean and responsive design with easy navigation.  

---

## Tech Stack  
- **Language**: Kotlin  
- **Framework**: Jetpack Compose  
- **Backend**: Firebase (Firestore, Authentication, Storage)  
- **Authentication**: Google Sign-In  
- **Architecture**: MVVM
